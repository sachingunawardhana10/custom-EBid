# Customs eBid

A microservices-based customs auction and bidding platform.

## Technology Stack

- Java 21
- Spring Boot
- Spring Security and JWT
- PostgreSQL
- Redis
- Apache Kafka
- Netflix Eureka
- Spring Cloud API Gateway
- Nginx
- Docker and Docker Compose
- AWS

## Project Status

Initial repository setup. Service implementation and detailed project documentation will follow the agreed team development requirements.

## Git Workflow

- `main`: stable, verified releases
- `develop`: integration branch
- `feature/*`: individual features
- `test/*`: testing and verification work

Feature branches should be merged into `develop` through pull requests.
